# Forgeproof

Versioned engineering specialists, exact signed bundles, and reproducible verification for AI coding clients.

**Status: first milestone under development.** No production release or certification of Codex, Claude Code, ChatGPT, or Claude compatibility yet.

- `crates/contracts`: manifest and receipt contracts.
- `crates/catalog`: Minisign authenticity, exact file integrity and authorization.
- `apps/engctl`: local verifier CLI (in development).
- `apps/web`: local receipt inspector for Vercel (in development).
- `docs/design/architecture.md`: reviewed product architecture and milestone plan.
- `docs/evidence/progress.md`: decisions and execution evidence.

Production secrets and signing keys never belong in this repository. Test keypairs are generated in temporary directories and deleted.
